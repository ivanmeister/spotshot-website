Импорт спотов с GGPoker

По правилам GGPoker SpotShot не трогает его клиент. Выберите один из двух способов получить скриншоты, затем импортируйте их.

Способ 1: свои скриншоты во время игры

  1. Нажмите Win+Shift+S и выберите на верхней панели режим Окно (третья кнопка). Выбор запоминается.

  2. Кликните по столу. На скриншоте будет только это окно.

  3. В приложении Ножницы откройте Параметры (меню …) и включите Автоматически сохранять снимки экрана. Они попадают в ИзображенияСнимки экрана.

  4. По желанию: там же разрешите клавише Print Screen открывать «Ножницы», или назначьте в PowerToys Keyboard Manager клавишу Ctrl+4 (как в SpotShot) на Win+Shift+S.

  5. В Настройках SpotShot укажите Папка скриншотов: ИзображенияСнимки экрана. SpotShot предложит новые скриншоты при каждом запуске.

  • Стол: один раз, когда решение за вами.
  • Лобби: один раз за турнир, на списке призовых. Сначала растяните окно лобби, чтобы были видны все строки призовых. Если не помещаются, прокрутите и снимите ещё раз.

Выключите Screen Guard в GGPoker (Game Settings, Client Security), иначе скриншоты будут чёрными.

Способ 2: PokerCraft после игры

  1. Откройте my.pokercraft.com, My Tournaments.

  2. Отметьте турнир.

  3. Откройте Game History и нажмите на раздачу.

  4. В окне раздачи, в режиме фишек, нажмите значок загрузки (первый в заголовке).

  5. Откройте Tournament Info и нажмите его значок загрузки.

Берите оба файла из одного турнира: SpotShot сопоставляет их по названию.

Импорт и анализ

  1. Закройте все покерные клиенты.

  2. Нажмите Импорт скриншотов или перетащите файлы в SpotShot.

  3. В разделе Снимки стола отметьте нужные.

  4. Нажмите Анализировать.

Где найти в библиотеке

Каждый скриншот станет спотом в разделе Все споты, новые сверху.

Лобби без стола даёт спот Только структура.

Откройте спот: Скопировать раздачу для солвера или Экспорт в HRC.

Не только GGPoker

Импорт работает для всех румов, которые поддерживает SpotShot.
